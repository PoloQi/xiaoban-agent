# 分阶段执行路线

## 1. 总体规则

- 一次只推进一个阶段；
- 每个阶段先完成最小纵向闭环，再补非关键体验；
- 同一轨道的退出门槛未全部通过，不进入该轨道下一阶段；
- 阶段内出现重大安全或架构问题时缩小范围；
- 当前路线图变化必须更新本文件和当天开发日志。
