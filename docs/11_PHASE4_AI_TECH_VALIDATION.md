## 2. 模型决策

采用DeepSeek官方OpenAI兼容API：

| 配置 | 4A.1固定值 |
|---|---|
| Provider | `deepseek` |
| Base URL | `https://api.deepseek.com` |
| Endpoint | `/chat/completions` |
| Model | `deepseek-v4-pro` |
| Thinking | `disabled` |
| Streaming | `false` |
| Response format | `json_object` |
| Timeout | 最长12000毫秒 |
| Retry | 不自动重试 |
| Output tokens | 默认800，允许64—2000 |

使用Node.js 22原生`fetch`，不增加模型SDK。供应商和数据边界详见`docs/decisions/ADR-003-DEEPSEEK-MODEL-GATEWAY.md`。

## 3. 共享契约

内部请求包含UUID请求标识、提示词版本、系统提示和合成用户提示。候选响应严格包含：

- `intent`：普通支持、活动建议、知识回答或拒答；
- `reply`：最多800字符的候选文字；
- `contentSlugs`：最多3个内容slug；4A.1不验证其真实存在，因此不得展示。

应用结果固定包含`status: unreviewed`。追踪元数据包含供应商、模型、提示词版本、输出结构版本、耗时和Token用量。`reasoning_content`、API Key、供应商原始响应和额外字段不能进入应用契约。

## 4. 秘密与本地运行

对话中曾出现的旧密钥视为已泄露，不能使用。轮换后的新密钥不得发送到对话、代码、日志、截图、命令参数或前端；由用户手动写入已被Git忽略的：

`D:\code\agent\.local\model-secrets\deepseek.env`

文件只需使用`.env.example`列出的变量名。4A.1真实冒烟命令：

`pnpm --filter @xiaoban/api ai:smoke:deepseek`

命令只发送一条虚构、无个人信息的短提示，只打印结构校验状态、供应商、模型、版本、耗时和Token用量，不打印输入或候选正文。

## 5. 故障安全

- 缺密钥、非法Base URL、非法模型或越过12秒上限：配置失败，不建立外部连接；
- 网络、429或供应商5xx：返回内部`MODEL_UNAVAILABLE`；
- 非JSON、模型标识不符或候选结构不符：返回`MODEL_RESPONSE_INVALID`；
- 输入不符合共享契约：返回`MODEL_REQUEST_INVALID`；
- 所有错误消息只含稳定错误码或字段名，不含密钥、提示词、候选、响应正文或内部异常；
- 4A.1没有产品展示路径，因此模型故障不影响阶段3静态活动、知识和离线能力。

## 8. 4A.2.1输入去标识

范围仅为内部合成文本的本地安全预处理，不调用模型、不连接数据库、不注册API或页面，也不落库和记录输入正文。

共享契约固定为：

- 请求：UUID `requestId`和1—2000字符`text`；
- 放行：`decision: allow`、去标识后的`sanitizedText`、唯一替换类别和`input-deidentification-2026-08-v1`策略版本；
- 阻断：`decision: block`、唯一稳定原因码和策略版本，不包含原始或去标识文本；
- 替换类别：手机号、邮箱、中国居民身份证号；
- 阻断原因：疑似姓名、学校全称、详细地址、联系人、秘密和提示注入。

当前验证：

- 契约实现前新增2项用例按预期失败，实现后契约测试20/20通过；
- 处理器实现前新增测试套件按预期因模块不存在而失败，实现后API单元测试25/25通过；
- 覆盖无标识放行、三类替换、六类阻断、结果不含原文、非法输入稳定错误和错误不回显；
- `pnpm check`通过：秘密扫描、全工作区类型检查、45项契约/单元测试以及Web/API生产构建成功。

## 9. 4A.2.2审核内容检索

范围仅为内部合成`allow`输入到MySQL审核内容的确定性检索，不调用模型、不注册API或页面、不新增迁移，也不记录检索原文。

共享契约与实现固定为：

- 请求：UUID `requestId`、4A.2.1 `allow`结果、`9_11`或`12_14`年龄段、`activity`或`knowledge`类型和1—3条限制；
- 资格：当前活动版本、`published`、`approved`、已生效、未过期且年龄匹配；阶段3儿童读取与AI检索复用同一查询和公开详情映射；
- 排序：去除占位符后提取中文双字片段及英文/数字词；标题命中3分、摘要命中1分、0分排除、同分按slug稳定排序；
- 结果：最多3项正整数分数和阶段3儿童安全详情，追踪输入策略和`reviewed-content-retrieval-v1`；
- 故障：非法或阻断输入为`RETRIEVAL_REQUEST_INVALID`且不访问数据库；数据库和内容解析异常为`RETRIEVAL_UNAVAILABLE`，错误不包含内部详情。

## 10. 4A.2.3输出审核与静态降级

范围仅为严格结构化候选和本次审核检索结果的确定性审核，不调用模型、不注册API或页面、不落库或记录回复正文。

固定规则：

- 候选的所有slug必须来自本次检索；活动建议和知识回答必须至少引用一项对应类型的审核内容；
- 阻断外部联系方式或链接、危险指令、医疗/心理/法律专业越界、依赖排他话术和系统提示词泄露；
- 审核通过只返回原结构化候选和`output-safety-2026-08-v1`；
- 审核失败只返回固定静态文案、本次审核内容slug、稳定原因码和策略版本，不携带被拒候选；
- 有审核内容时引导查看审核内容；没有内容时引导暂停并向身边可信任成年人求助。

## 11. 4A.2.4内部安全编排闭环

范围仅为后端内部合成验证，不注册API或页面、不持久化输入/回复、不提供长期记忆、工具或通知。

闭环顺序和失败关闭：

1. 严格校验UUID、最多700字符合成文本、年龄段和内容类型；调用方不能传系统提示词；
2. 本地去标识；命中阻断时直接静态降级，不检索、不调用模型；
3. MySQL审核内容检索；故障或无匹配时静态降级，无匹配不调用模型；
4. 代码生成`internal-grounded-v1`固定提示词，仅发送去标识文本和审核内容的slug、类型、标题、截断摘要；
5. DeepSeek返回严格未审核候选，再经4A.2.3审核；任何故障或拒绝都转为静态结果；
6. 最终结果带`internal-ai-pipeline-v1`以及输入、检索、提示词、输出和模型追踪版本，不含原始输入、提示词、供应商原文或被拒候选。

## 12. 阶段4结论与保留限制

阶段4退出门槛已达到：去标识和阻断发生在模型之前；模型原文和解析失败不可展示；所有依赖故障有固定静态降级；普通、越权和依赖话术用例均有确定性验证；模型闭环没有儿童入口。

保留限制：当前去标识、词法检索和输出关键词审核只适用于内部成人与合成数据，不能替代完整语义风险引擎、安全评测、真实未成年人隐私合规、监护授权、人工值守或供应商条款审查。阶段5确认并完成前不得向儿童开放模型。
