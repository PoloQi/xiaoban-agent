## 2. 已确认风险等级

| 等级 | 工程边界 | 处置 |
|---|---|---|
| L0 | 无聊、短期压力、普通冲突和一般请求 | 继续阶段4审核AI流程 |
| L1 | 持续难过、孤立、睡眠困扰或自我否定，无危险意图 | 有边界支持并提供找现实成年人选项 |
| L2 | 霸凌、疑似侵害、诱骗诈骗、隐私索取、危险模仿、含糊自伤/伤人表达 | 停止自由生成，固定安全动作，要求人工承接并建立事件 |
| L3 | 明确自伤/伤人意图、计划、工具或时间，或正在发生的人身危险 | 立即停止生成，固定应急动作，必须人工介入 |

分类不是医疗或心理诊断。否定、引用、第三人称、假设和多轮上下文必须在规则与评测中单独处理；分歧取更高风险，人工降低等级不能恢复此前被阻断的模型回复。

## 3. 风险类别

- `ordinary`：仅L0；
- `persistent_distress`：仅L1；
- `bullying`、`abuse_exploitation`、`fraud_privacy`、`dangerous_imitation`：仅L2；
- `self_harm`、`harm_to_others`：可为L2或L3，由明确性、计划、工具、时间和即时性区分；
- `active_danger`：仅L3。

## 4. 5A共享契约与固定动作

- 策略版本：`risk-policy-2026-08-v1`；
- 非法等级/类别组合在映射前拒绝，错误只返回`RISK_DISPOSITION_INVALID`；
- L0结果固定`reviewed_ai`，L1固定`support_and_offer_adult`；
- L2/L3固定`fixed_safety`、`requiresHuman=true`、`eventRequired=true`、`notificationStatus=not_sent`；
- L2/L3按九种等级/类别组合提供至少两步现实行动；
- 固定动作不含“已通知/已送达/已看到/正在处理”、未经核验电话号码、诊断、治疗或救援承诺；
- 当前模块不检查文本，因此不能用5A结果声称风险识别已实现。

### 7.1 5B确定性规则引擎

规则版本`risk-rules-2026-08-v1`，按以下顺序首次命中即返回：

1. 正在发生的人身危险为L3；
2. 自伤/伤人表达结合即时性信号区分L2与L3；
3. 诈骗隐私、侵害诱骗、霸凌和危险模仿为L2；
4. 持续时间与困扰信号同时存在为L1；
5. 其余为L0。

第三人称、引用和假设不降低风险。明确否定只遮蔽相邻的“马上、现在、行动、计划、何时”等即时性信号，自伤/伤人类别仍至少L2。规则输出不含文本，只含等级、类别、规则ID和版本。
