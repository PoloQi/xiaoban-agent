## 2. 已确认产品规则

- 首批内容类型只有`activity`和`knowledge`；
- 年龄范围为`9_11`、`12_14`或`both`；
- 内容身份与不可变版本分离，修改必须创建新版本；
- 版本审核状态为`draft`、`in_review`、`approved`或`rejected`；
- 内容生命周期为`draft`、`published`或`disabled`；
- 作者不能审核自己的版本；
- 发布和回滚只能选择属于该内容且已经审核通过的版本；
- 过期、停用或未发布版本不得被儿童端和后续AI检索；
- 每个版本记录来源、年龄、有效期和风险标签；
- 阶段3只使用合成内容和不对应真实人员的内部身份标识；阶段4A.2.2复用同一可见内容查询与公开详情映射，未改变阶段3儿童读取行为。

数据库落实作者不能自审、活动版本不能跨内容引用、有效期结束必须晚于开始时间等结构约束。阶段3B服务层已落实审核通过后才能发布、回滚只能选择更早的已批准且未过期版本等状态机规则。

## 3. 共享内容契约

公共字段：

| 字段 | 规则 |
|---|---|
| `title` | 2—80字符 |
| `summary` | 4—240字符 |
| `ageBand` | `9_11`、`12_14`、`both` |
| `source` | 类型、2—160字符来源名、可选URL |
| `validFrom`/`expiresAt` | ISO时间；结束时间晚于开始时间 |
| `riskTags` | 最多6个受控标签 |

活动正文只包含时长、室内/室外、材料、成人陪同等级和1—6个步骤。知识正文允许`general_growth`、`emotional_social`、`digital_safety`和`body_boundaries`主题及1—6个短段落，并可携带一个与正文共同审核发布的情景练习。练习严格包含场景标识/标签、题干、恰好三项唯一选择、存在于选项中的正确项、正确/错误标题、原因解释和1—4条行动步骤。

允许的首批风险标签为一般信息、数字安全、户外、天气敏感、成人陪同和需要材料。当前不录入医疗、心理诊断、紧急电话或未经专家审核的身体保护内容。

## 4. 数据结构

### `content_items`

保存内容类型、稳定slug、生命周期和当前发布版本。草稿不能有当前发布版本；已发布或停用内容必须保留当前版本。复合外键保证当前版本属于同一内容。

### `content_versions`

保存不可变版本号、审核状态、标题、摘要、类型化JSON正文、年龄、来源、有效期、风险标签、作者和创建时间。同一内容的版本号唯一。

### `content_reviews`

保存单个版本的一次最终审核结论、理由、作者、审核人和时间。复合外键验证作者与版本一致，检查约束禁止作者和审核人为同一身份。驳回后修改必须创建新版本。

### `content_commands`

保存内容写命令的全局唯一`requestId`、合成操作者、命令类型、请求摘要、目标内容和已验证响应，用于重复提交的精确重放。同一`requestId`的身份、命令或载荷不一致时返回`IDEMPOTENCY_CONFLICT`。

四个阶段3表均使用InnoDB、`utf8mb4`和UTC时间。没有儿童身份、联系方式或真实运营人员资料。

## 5. 合成身份边界

阶段3B复用只保存SHA-256令牌摘要的`access_sessions`，新增`content_author`和`content_reviewer`角色。内容角色的会话不能关联儿童或监护登记；儿童和监护服务拒绝把内容角色当作自身角色使用。测试按运行时随机创建并在结束时删除合成会话，不提供固定开发令牌、角色请求头或运营账号创建接口。

真实内容审核员账号、MFA和生产权限属于后续内部Alpha与试点准入能力，不能用合成身份代替真实审批责任。

## 6. 阶段3B内部API与状态机

所有写接口必须携带UUID格式的`requestId`，所有接口必须使用Bearer会话令牌：

| 接口 | 角色 | 约束 |
|---|---|---|
| `POST /api/v1/internal/content/items` | `content_author` | 创建内容和不可变V1草稿；slug唯一 |
| `POST /api/v1/internal/content/items/:itemId/versions` | `content_author` | 不能为停用内容或存在未决草稿的内容创建版本 |
| `POST /api/v1/internal/content/items/:itemId/versions/:versionId/submission` | 该版本作者 | 仅`draft`可提交为`in_review` |
| `POST /api/v1/internal/content/items/:itemId/versions/:versionId/review` | 不同的`content_reviewer` | 仅`in_review`可批准或驳回，理由必填 |
| `POST /api/v1/internal/content/items/:itemId/publication` | `content_reviewer` | 仅发布已批准、未过期、非当前版本 |
| `POST /api/v1/internal/content/items/:itemId/rollback` | `content_reviewer` | 仅回滚至更早的已批准且未过期版本 |
| `POST /api/v1/internal/content/items/:itemId/disable` | `content_reviewer` | 仅已发布内容可停用，原因必填 |
| `GET /api/v1/internal/content/items/:itemId` | 两种内容角色 | 返回内部版本与审核详情 |

状态写入使用事务和内容行锁。状态变化记录`content.item.created`、`content.version.created`、`content.version.submitted`、`content.version.reviewed`、`content.item.published`、`content.item.rolled_back`和`content.item.disabled`审计动作；审计元数据不复制内容正文或会话令牌。

这些接口目前只用于本地合成验证，不能作为真实运营后台或生产审核登录方案。

## 7. 阶段3C儿童只读能力

儿童端只提供以下两个Bearer鉴权接口：

| 接口 | 返回范围 |
|---|---|
| `GET /api/v1/child/content` | 分页列表，可按`all`、`activity`或`knowledge`筛选 |
| `GET /api/v1/child/content/:slug` | 单条活动步骤，或知识段落与可选情景练习详情 |

服务端查询同时强制以下条件：

- 会话属于未撤销的活跃儿童账号；
- 内容生命周期为`published`；
- 读取的版本必须等于内容当前版本；
- 当前版本审核状态为`approved`；
- 当前时间不早于`validFrom`且早于`expiresAt`；
- 版本年龄为儿童年龄段或`both`。

未发布、未审核、已驳回、已停用、未生效、已过期或年龄不匹配内容不会进入列表，详情统一返回`CONTENT_NOT_FOUND`，不泄露隐藏内容是否存在。监护和内容运营角色不能调用儿童接口。

儿童响应只包含展示必要的slug、类型、标题、摘要、来源名、有效期、公开`revision`和类型化正文；知识列表另含`topic`与`hasQuiz`，知识详情可返回经过同版本审核的`quiz`；详情提供固定公开审核组标识与审核时间，仍不暴露真实审核人员。列表另含公开`catalogRevision`。公开修订值是内部版本ID或可见目录的SHA-256摘要截断值，只用于缓存失效，不包含内部内容ID、版本号、作者、真实审核人、审核理由、风险标签或来源URL。

正式React页面保留“山野观察手册”内容目录，并增加 prototype 对齐的独立“安全成长小站”：首页和“我的”均可进入三类知识，每类打开独立三选一情景，正确与错误均展示原因和行动步骤。答题结果只存在当前页面 React 状态中，返回中心即清除，不新增写接口、分数或历史记录。

## 8. 阶段3D缓存与弱网标准

- 生产构建注册原生Service Worker，缓存名显式版本化；激活新版本时删除旧的同前缀应用壳缓存；
- Service Worker只处理同源GET静态资源和页面导航，明确跳过所有`/api/`路径，不缓存Bearer令牌、API响应、内部审核数据或未发布内容；
- 公开列表和已打开详情只保存在当前标签页`sessionStorage`，由共享契约再次校验，按`9_11`或`12_14`年龄段精确匹配；
- 缓存最长24小时且不得越过单条`expiresAt`；在线列表成功后使用slug和`revision`淘汰已删除或换版详情；
- 服务不可用时可显示最近保存的公开审核内容，并明确提示当前为弱网回退；鉴权失败、角色错误或账号停用时不允许回退；
- 经契约校验的儿童模式快照只服务当前浏览器会话的断网重载；退出儿童内容或监护撤回时同步清理儿童会话、模式快照和内容缓存；
- 不提供离线写入、后台同步、长期内容存储、离线AI、真实内容导入或跨设备缓存。
