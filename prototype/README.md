# 小伴 AI成长伙伴高保真原型

这是依据 `AI陪伴智能体_PRD_V0.1.md` 实现的移动端H5/PWA高保真原型。

## 本地运行

在 `D:\code\agent\prototype` 目录启动任意静态文件服务器，例如：

```powershell
python -m http.server 4173
```

然后访问：

```text
http://127.0.0.1:4173
```

## 推荐演示顺序

1. 欢迎页点击“直接进入演示”；
2. 点击右上角“演示”；
3. 依次体验“从无聊到行动”“从想念到连接”“从风险到求助”；
4. 在风险路线末尾进入监护端，查看隐私边界和风险承接；
5. 在“我的”中体验无网络状态和重置功能。

## 重要限制

- 全部账号和数据均为虚构；
- AI回复为预设分支，不是实时大模型输出；
- 风险识别和通知均为演示，不具备真实救援能力；
- 语音按钮不会录音或上传；
- 原型不读取定位、通讯录、相册或其他App数据。

## 后续升级接口

- 将当前状态对象替换为服务端用户与会话API；
- 将预设对话替换为带输入/输出审核的大模型服务；
- 将静态活动和知识卡替换为可审核的内容管理系统；
- 将模拟风险提醒替换为可验证送达、确认和超时升级的工单流程；
- 正式试点前完成监护同意、数据保护和未成年人安全专项审查。
